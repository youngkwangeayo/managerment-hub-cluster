# ArgoCD 디렉토리 구조

Management Hub Cluster의 ArgoCD 구성 디렉토리입니다.
Hub-and-Spoke 패턴으로, 이 ArgoCD가 여러 워크로드 클러스터를 중앙에서 관리합니다.

---

## 전체 구조

```
argocd/
├── bootstrap/                     # 1단계: ArgoCD 최초 부트스트랩
│   ├── init-hub-repo-secret.yaml  # Git 저장소 연결용 Secret (수동 적용)
│   └── root-hub-setup.yaml        # hub-setup App 등록 (수동 적용)
│
├── hub-setup/                     # 2단계: Hub 클러스터 기본 세팅 (Helm Chart)
│   ├── Chart.yaml
│   ├── values.yaml                # Google SSO, 레포지토리, 프로젝트, 클러스터 등 설정값
│   └── templates/
│       ├── 0-configmap.yaml       # argocd-cm (Google SSO 설정)
│       ├── 0-rbac-configmap.yaml  # argocd-rbac-cm (권한 설정)
│       ├── 0-secret.yaml          # 기타 시크릿
│       ├── 1-ingress.yaml         # ArgoCD UI 인그레스 (mgmt-hub.n*****.co.kr)
│       ├── 1-repository.yaml      # Bitbucket Git 저장소 연결 Secret
│       ├── 2-projects.yaml        # AppProject (클러스터별 권한 분리)
│       └── 3-clusters.yaml        # 타겟 클러스터 등록 Secret
│
└── clusters/                      # 3단계: 워크로드 클러스터별 App 관리
    ├── cms/                       # CMS 클러스터
    │   ├── root-app-dev.yaml      # CMS dev 환경 루트 App
    │   ├── root-app-prod.yaml     # CMS prod 환경 루트 App
    │   └── apps/                  # CMS App 목록 Helm Chart
    │       ├── Chart.yaml
    │       ├── templates/
    │       │   └── apps.yaml      # Application 리소스 템플릿
    │       ├── values.yaml        # 공통값 (클러스터 서버, 레포, 프로젝트)
    │       ├── values-dev.yaml    # dev 환경별 App 목록
    │       └── values-prod.yaml   # prod 환경별 App 목록
    │
    └── aiagent/                   # AI Agent 클러스터
        ├── root-app-dev.yaml      # aiagent dev 환경 루트 App
        ├── root-app-prod.yaml     # aiagent prod 환경 루트 App
        └── apps/                  # aiagent App 목록 Helm Chart
            ├── Chart.yaml
            ├── templates/
            │   └── apps.yaml
            ├── values.yaml
            ├── values-dev.yaml
            └── values-prod.yaml
```

## 단계별 역할

### 1단계: bootstrap (수동 1회 적용)

ArgoCD가 처음 설치된 직후, 자기 자신을 GitOps로 관리하기 위한 최소한의 리소스를 **kubectl로 직접 적용**합니다.

| 파일 | 역할 |
|------|------|
| `init-hub-repo-secret.yaml` | ArgoCD가 `mgmt-hub-cluster` Bitbucket 레포를 읽을 수 있도록 SSH Key Secret 등록 |
| `root-hub-setup.yaml` | `hub-setup` Helm Chart를 바라보는 ArgoCD Application 등록. 이후 모든 설정은 Git으로 관리됨 |

```bash
# 최초 1회만 수동 적용
kubectl apply -f argocd/bootstrap/init-hub-repo-secret.yaml
kubectl apply -f argocd/bootstrap/root-hub-setup.yaml
```

---

### 2단계: hub-setup (Helm Chart, ArgoCD가 자동 동기화)

`root-hub-setup.yaml`이 등록되면, ArgoCD가 이 Helm Chart를 자동으로 sync합니다.
**sync-wave 순서**로 리소스가 순차 생성됩니다.

| Wave | 파일 | 역할 |
|------|------|------|
| 0 | `0-configmap.yaml` | Google SSO(Dex) 연동 설정 |
| 0 | `0-rbac-configmap.yaml` | ArgoCD UI 접근 권한 설정 |
| 0 | `0-secret.yaml` | 추가 시크릿 |
| 1 | `1-ingress.yaml` | `mgmt-hub.n*****.co.kr` 인그레스 생성 |
| 1 | `1-repository.yaml` | 워크로드 레포(cms-k8s, aiagent-k8s 등) SSH 연결 등록 |
| 2 | `2-projects.yaml` | AppProject 생성 — 클러스터별 소스 레포/배포 대상 권한 분리 |
| 3 | `3-clusters.yaml` | 타겟 EKS 클러스터 등록 (BearerToken + CA 인증서) |

`values.yaml`에서 레포지토리, 프로젝트, 클러스터 정보를 한 곳에서 관리합니다.

---

### 3단계: clusters (워크로드 클러스터 App 관리)

각 워크로드 클러스터에 배포할 ArgoCD Application들을 **App of Apps 패턴**으로 관리합니다.

#### 흐름

```
root-app-dev.yaml (Hub ArgoCD에 등록)
    └─> apps/ Helm Chart를 렌더링
            └─> values-dev.yaml의 apps 목록 → 각각 Application 리소스 생성
                    └─> 각 App이 워크로드 레포(cms-k8s 등)의 특정 경로를 배포
```

#### 파일 역할

| 파일 | 역할 |
|------|------|
| `root-app-dev.yaml` | Hub ArgoCD에 등록하는 루트 Application. `apps/` 디렉토리를 소스로 지정 |
| `root-app-prod.yaml` | 동일하되 prod 환경 values 사용 |
| `apps/values.yaml` | 클러스터 서버 주소, 레포 URL, ArgoCD 프로젝트 등 공통값 |
| `apps/values-dev.yaml` | dev 환경에서 배포할 App 목록 (name, namespace, path, valueFiles) |
| `apps/values-prod.yaml` | prod 환경에서 배포할 App 목록 |
| `apps/templates/apps.yaml` | values의 apps 목록을 Application 리소스로 렌더링하는 Helm 템플릿 |

## 등록된 워크로드 클러스터

| 클러스터 | 환경 | 레포 | AppProject |
|---------|------|------|------------|
| `dev-cms-k8s-cluster` | dev | `cms-k8s` | `dev-cms-k8s-project` |
| `dev-aiagent-k8s-cluster` | dev | `aiagent-k8s` | `dev-aiagent-k8s-project` |

## 전체 플로우 요약

```
[최초 1회]
  kubectl apply bootstrap/
        │
        ▼
  ArgoCD가 hub-setup Helm Chart를 sync
        │
        ├─ Google SSO 설정
        ├─ Git 레포 연결 (cms-k8s, aiagent-k8s, ...)
        ├─ AppProject 생성 (권한 분리)
        └─ 타겟 클러스터 등록 (cms, aiagent, ...)

[이후 지속적으로]
  clusters/{cluster}/root-app-*.yaml → Hub ArgoCD에 수동 등록 (또는 hub-setup에 추가)
        │
        ▼
  apps/ Helm Chart → values-{env}.yaml의 App 목록을 Application으로 생성
        │
        ▼
  각 Application이 워크로드 클러스터에 서비스 배포
```
