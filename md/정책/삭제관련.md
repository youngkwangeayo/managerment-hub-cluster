기존에 떠 있는 실제 서비스들은 전혀 건드리지 않고, ArgoCD 상의 '루트 앱 껍데기'만 안전하게 갈아끼우는 방법입니다. (이것을 Non-Cascading Delete 또는 Orphan 삭제라고 부릅니다.)

1단계: 기존 루트 앱을 '안전하게' 삭제하기
가장 추천하는 방법은 ArgoCD UI를 사용하는 것입니다.

ArgoCD 웹 UI에 접속합니다.

기존에 있던 이름(prod-aiagent-root-apps)의 타일을 찾아서 [Delete] 버튼을 누릅니다.

⚠️ (가장 중요) 삭제 확인 창이 뜰 때, Cascade 체크박스가 켜져 있다면 반드시 체크를 해제하세요! (비활성화 상태로 만들어야 합니다)

입력창에 앱 이름을 타이핑하고 삭제를 진행합니다.
이렇게 하면 ArgoCD 목록에서 루트 앱만 쏙 사라지고, 하위 앱들과 실제 클러스터의 파드들은 털끝 하나 다치지 않고 그대로 살아있게 됩니다.
